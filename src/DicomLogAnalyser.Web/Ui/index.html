Filters

Any text is found anywhere in the events, including the middle of IDs, UIDs and words and inside stack traces (for example 840.1136 or ACC000). Upper/lower case and accents are ignored. Several words must all appear; use "quotes" for an exact phrase with spaces and -word to exclude. Choose a category to search only within it.

Live view

Follows a log file as it is written, like a tail viewer: new lines appear every second. The file is read directly and only read. Errors are red, warnings amber; text you enter under Highlight is marked in your highlight colour.

Sources

A source is one folder with log files. Add one source for each folder you want to analyse, for example the B3DWEB Gateway folder and the DICOM Router folder of each site. You can add as many folders as you need; they are searched together.

Folders are only read, never changed. New lines are picked up automatically. Use Files to choose which files of a folder are analysed (at most 5 days).

Import a log bundle

Use this for logs from computers that this analyser cannot reach. On that computer, put the log folder into a .zip file (see README, "Collecting a bundle"), bring it here and upload it. The original files on that computer are not changed.
